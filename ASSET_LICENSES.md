## 2. Audio Effects (Sound Effects)

All 4 sound effects are original synthesized audio files procedurally generated by the project utility [`tool/generate_audio.dart`](file:///e:/study%20File/Games/Arrow-Escape-Puzzl/tool/generate_audio.dart). They are 16-bit PCM Mono WAV files at 44,100 Hz.

1. **`assets/audio/tap.wav`**:
   - **Type**: Crisp woodblock/cardboard click (60ms, exponential decay envelope, 750Hz to 220Hz downward sweep with subtle noise transient).
   - **Author**: Procedurally generated by project tool.
   - **License**: CC0 1.0 Universal (Public Domain Dedication).

2. **`assets/audio/exit.wav`**:
   - **Type**: Delivery package glide whoosh (220ms, rising harmonic frequency sweep from 320Hz to 880Hz).
   - **Author**: Procedurally generated by project tool.
   - **License**: CC0 1.0 Universal (Public Domain Dedication).

3. **`assets/audio/bump.wav`**:
   - **Type**: Gentle parcel thud / bounce (120ms, damped sine wave with frequency drop from 180Hz to 90Hz).
   - **Author**: Procedurally generated by project tool.
   - **License**: CC0 1.0 Universal (Public Domain Dedication).

4. **`assets/audio/win.wav`**:
   - **Type**: Victory chime / fanfare arpeggio (500ms, harmonic bell tones on C5-E5-G5-C6 with decay envelope).
   - **Author**: Procedurally generated by project tool.
   - **License**: CC0 1.0 Universal (Public Domain Dedication).

No copyrighted, third-party, or unlicensed sound effects, music tracks, or trademarked assets are used.
